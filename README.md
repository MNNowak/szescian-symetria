# Sześcian - osie i płaszczyzny symetrii

Interaktywna gra edukacyjna do ćwiczenia elementów symetrii sześcianu:

- osie obrotu 4-krotne, 3-krotne i 2-krotne,
- płaszczyzny lustrzane {100} i {110},
- obrót, skalowanie i przesuwanie sceny,
- osobne przewijanie sceny i panelu sterowania,
- widok dostosowany do przeglądarek desktopowych i mobilnych.

Strona startowa dla GitHub Pages to `index.html`.
